# Smart Inventory and Dynamic Discount Management System

## Project Overview
Smart Inventory is a web-based application designed to manage product inventory, monitor stock levels, track expiry dates, and apply dynamic discounts.

## Features
- User Login and Authentication using JWT
- Add and Update Products
- Stock In and Stock Out Management
- Low Stock Alerts
- Near Expiry Product Tracking
- Rule-Based Dynamic Discounts
- Inventory Dashboard

## Technologies Used
- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- Spring Security
- JWT Authentication
- MySQL
- React.js
- HTML, CSS, JavaScript
- Maven
- Git and GitHub

## Project Purpose
The main goal is to reduce product wastage, manage inventory efficiently, and support timely discounts on products nearing expiry.
